# Student Marks Manager

A Python console application to manage student marks.

## Features
- Add students with 5 subject marks
- Calculates total, average and grade
- Finds the class topper
- Saves the report to a text file

## Concepts Used
Python, lists, functions, loops, conditions, file handling

## How to Run
1. Install Python
2. Run: python student_marks_manager.py
3. Choose options from the menu
